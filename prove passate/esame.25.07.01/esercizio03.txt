Scrivere lo pseudocodice di una funzione ricorsiva verifica(x, S) che,
dato un nodo radice x di un RBT e un intero S,
verifichi se esiste almeno un cammino dalla radice x a una foglia tale che la somma delle chiavi dei nodi lungo il cammino sia esattamente S

//RIVEDERE
VERIFICA(x, S)
	delta = S - x.value
	//check if is leaf
	if x->left == NULL AND x->right == NULL
		return delta == 0 //TRUE or FALSE
	//check left subtree
	if x->left != NULL
		return VERIFICA(x->left, delta)
	//check right subtree
	if x->right != NULL
		return VERIFICA(x->right, delta)
